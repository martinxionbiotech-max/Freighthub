# Freighthub

China → GCC freight intelligence. Middle East only.

## Scope
- 6 GCC countries: Saudi Arabia, UAE, Qatar, Kuwait, Oman, Bahrain
- Ports, routes, customs, certification, sectors, comparisons
- Live updates feed (`/updates/`) — no calculators, no directory, no Europe content

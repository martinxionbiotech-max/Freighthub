## 2. 一致性核对

| 标题 / 描述 | 九页 title 20–57 字符，description 136–153 字符 |

## 3. 与 Google 搜索要求的对应

| 要求 | 落地 |
|---|---|
| E-E-A-T：谁负责 | About 写明发布主体、独立性、资金来源、选题标准；Contact 给出唯一可核验渠道 |
| 透明度 | 更正流程、申诉、响应时效、无主体信息的说明全部公开 |
| YMYL 谨慎 | Disclaimer 与 Terms 明确「非海关/法律/税务建议」，要求向主管机关核验 |
| 不误导 | 明确区分区间、模拟与报价；计算器声明只做算术 |
| 可抓取与可发现 | 九页均在 sitemap、llms.txt、页脚可达；无 noindex |
| 结构化数据准确 | Organization/WebSite/BreadcrumbList 全站；未虚假声明资质或评分 |
| 政策完整性 | privacy / terms / cookies / accessibility / disclaimer 五件套齐备，且各自有独立 URL |

## 4. 仍需业主确认

1. **运营主体**：注册号、注册地址、法定名称（若已注册）。目前三页统一写「不公布」，诚实但仍是信任缺口。
2. **适用法律**：Terms 目前按运营地写为中国法，需确认。
3. **服务承诺**：5/10/15/30 工作日与半年复核是代理按行业惯例设定的政策值，需确认为可执行承诺。
4. **部署**：站点仍未上线（`freighthub.net` 为停放页），以上内容只在仓库与本地构建中。
